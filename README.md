# 🌸 Mood Journal – Mood-Based Journaling Web Application

## 📌 About the Project

Mood Journal is a web-based journaling application that allows users to record their daily thoughts and emotions. It provides a simple, interactive space to express feelings, explore different moods and discover mood-based music recommendations.

The application uses a mood-based interface that dynamically changes its theme according to the user's selected emotion.

## ✨ Features

- **Mood Selection:** Choose from six moods: Happy, Sad, Angry, Anxious, Calm and Tired.
- **Personal Journaling:** Write and save daily thoughts and experiences.
- **Dynamic Themes:** The interface changes its appearance based on the selected mood.
- **Music Recommendations:** Displays predefined music recommendations for different moods.
- **Journal History:** View previously added journal entries during the current session.
- **Mood Analytics:** Displays mood summaries and visual representations.
- **Interactive Interface:** Provides notifications and dynamic webpage updates.

## 🛠️ Technologies Used

- HTML5 – Webpage structure.
- CSS3 – Styling, layouts and mood-based themes.
- JavaScript – Application logic, DOM manipulation and state management.
